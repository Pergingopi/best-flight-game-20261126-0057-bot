Meridian Courier — a complete, original flight game: fly the island mail run in a little prop plane, thread eight glowing rings over sea, mountains and a harbour city, then put her down gently on the strip. A procedural island rendered in real 3D-ish voxel terrain, chase and cockpit views with lit instruments, a full HUD (airspeed, altitude, heading, throttle, vertical speed), keyboard and mouse controls, an autopilot that flies the real rules, and procedural engine and wind sound. Static files only — it plays offline in a desktop browser with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Fly with ↑ ↓ pitch, ← → roll, A / D rudder, W / S throttle, or steer with the mouse; C swaps chase and cockpit, O toggles the autopilot, M mutes, P pauses, R restarts.
